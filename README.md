- **Links**: [GitHub Repository](https://github.com/rishireddy-22/customer-churn-analysis)
- **Overview**:
  - Conducted end-to-end customer churn analysis uncovering behavioral indicators and attrition drivers.
  - Prepared and cleaned dataset, evaluated contract types and tenure correlations, and mapped churn distributions.
  - Summarized critical findings into an actionable executive report for proactive subscriber retention.

### 3. 🗄️ SQL Retail Insights

### 4. 📊 Marketing Campaign Performance Analysis

## ⚡ Local Setup & Development

### Frontend (`portfolio-frontend`)
```bash
cd portfolio-frontend
npm install
npm run dev
```
Runs at `http://localhost:5173`.

### Production Build
```bash
cd portfolio-frontend
npm run build
```
Generates production assets in `portfolio-frontend/dist/`.
